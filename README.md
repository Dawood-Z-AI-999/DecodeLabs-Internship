**🚀 Terminal To-Do List: Data Management Fundamentals📌**


**Project Overview:**
This project represents the logic phase of the DecodeLabs Junior Python Developer track. Rather than focusing on complex algorithms, this application is designed to demonstrate core Data Management principles. It serves as a foundational step before building massive databases by proving the ability to store, manage, and view multiple items within a single variable through programmatic logic.
**🧠 Core Concepts & Technical Skills**

This application is built around the fundamental IPO model for backend engines: Input (Data Entry), Process (Logic/Modification), and Output (Display/View).  

**Data Structures:**
Utilizes Python lists as dynamic arrays. 
Algorithmic Efficiency: Achieves O(1) time complexity by appending items to the end of the list,
capitalizing on pre-allocated space in the Heap.

**Memory Management:** 
Demonstrates an understanding of volatile containers by managing state within the application's runtime memory. 

**Python Fundamentals:**
Implements essential list operations (append and print loops) to build an interactive command-line interface.

**⚙️ How It Works:**
The program provides a clean, continuous terminal interface where users can seamlessly manage data:

**Add Tasks:**
Users can input a task (e.g., "Finish Python assignment") which is securely stored in the system's memory. 
**View Tasks:** 
The application iterates through the volatile memory and cleanly enumerates all active tasks.

**Exit:**
Safely breaks the loop and terminates the program's execution.
